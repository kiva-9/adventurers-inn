# 归途旅店：小镇三十日

原创中文单机旅店经营游戏，首个 30 日评议后可以继续经营。请先阅读 [目标与当前状态](GOAL.md) 和 [实际验证与限制](docs/VALIDATION.md)：本项目仍有明确的模拟深度和长期平衡限制。

需要 Node.js 22.12 或更新版本：

```sh
npm ci
npm run dev
```

浏览器打开 http://127.0.0.1:5187。WASD 或方向键移动，靠近门或人物按 E；地图可快速前往。管理面板自动暂停，关闭后使用顶部按钮继续。设置内可调音量、打开决策观察或可选增强对话。

第 30 日以前经营、采购、与人物交流、接取委托并组织远征，争取商会或守望者支持。评议结果出现后选择“继续经营”，保留本次评议并进入不设终止日的续营：公会会定期发布新采购与远征委托；资金紧张时可在公会每日做一次短工；周期供给请求需要权衡库存与两派支持。某些重大请求会中断等待，未回应会按说明处理。

自动存档保存在当前浏览器的 IndexedDB，也可使用三个手动槽位或导出 JSON；更换浏览器/清理站点数据前请先导出。关闭页面不会在后台推进时间。离线话题对话无需账号或密钥；可选 Ollama 代理默认关闭，见 [配置说明](server/README.md)，真实模型服务的验证状态见验证记录。

开发命令：`npm run typecheck`、`npm test`、`npm run build`、`npm run validate:sim`。`npm run preview` 在本机 5188 提供构建预览。浏览器测试 `npm run test:e2e`；如缺浏览器可先执行 `npx playwright install chromium`。15 分钟耐久测试默认不运行，需显式配置，详见验证记录。
