# 旅店帮手与营业

梅朵是有独立钱包和行程的雇员，而不是全镇即时生效的开关。雇佣时每天 08:00–20:00 为服务时段；健康至少 65、没有占用床位、人在旅店且没有正在前往其他地方时，才算在岗。受雇后她根据日程前往旅店；她未到岗、休息、伤病或道路不可达时，只有玩家本人在旅店才能供餐。她的健康、饥饿和睡眠仍按普通角色规则处理，受伤时优先治疗，没有草药则等待；补充草药后可以恢复。其他经营行为不需要她在岗。

每天结算时，如果旅店能支付 4 金，工资从旅店资金支出并转入梅朵钱包；不能支付时不产生虚构转账，明确记录工资未支付并暂停雇佣，本版不产生员工工资欠款。旅店租金仍按既有规则另行结算。受雇的梅朵不可同时加入玩家远征；未受雇而离镇时不能重新聘用。工资、员工状态和行程由已有世界状态保存，无新存档格式。

浏览器验证：`npx playwright test --config tests/staff.playwright.config.ts` 使用独立 5194 端口、新游戏 seed 101：旅店未到岗 → 玩家前往集市 → 时间推进 → 她到岗，随后跨日检查工资日志和导出状态中钱包增加。测试运行时的页面和事件截图为 `docs/evidence/staff-on-duty.png`、`staff-wages.png`。
