# 居民自主采购委托

初始诊所草药委托和续营后的周期采购委托未被玩家接取时，在截止前两天的日结开始竞争。系统从前九名可冒险者中挑选身体、疲劳和金钱符合条件、未在外、未占床且没有目的地的人；优先医术，再按余额和稳定 ID 排序。若无人符合条件，该委托保持可接并在次日日结重试；到期无人承接则显示过期。玩家已接取或完成的委托不会被抢走。

居民接取后先沿路径前往镇门，途中被预约，不可加入玩家队伍；抵达时再次检查体力、伤势和资金，再从本人钱包扣除 12 金，获得四份采购货物并离镇四小时。离镇角色不参加城镇的饥饿、工作、吃饭、对话和玩家远征。按存档 PRNG 判定后，成功者从镇门走到诊所交付，取得委托列明的发布者报酬（初始委托为 24 金）；失败者丢失货物、受伤，承担采购成本且无奖励。旅店资金、声望和支持度不因居民完成而增加。所有阶段、货物、时间和承接者保存在世界中；同一委托只结算一次。

货物和成本是小规模抽象：镇外供应商没有独立库存。只有诊所采购实现了自主全过程，其他三项仍沿用原来的简化竞争事件；续营后的同类采购委托可周期产生。角色跨场景路径仍采用项目现有的抽象通道，尚未使用场景家具碰撞。

另以亲历草药治疗的记忆作为谨慎角色接受遗迹远征风险的理由：检索考虑主题、重要性和近期性，不直接凭空增加关系。粮食、故事和药材等个人目标参与工作地点选择。记忆与目标只覆盖少数具体行为，并非通用计划或反思系统。
