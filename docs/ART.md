# 原创像素素材说明

本目录的 `public/assets/town-tiles.png`、`people.png` 和 `portraits.png` 是专为本项目绘制的原创程序化像素素材，无第三方图片或字体。它们由 `scripts/generate-assets.py` 确定性生成，成品随仓库提交；正常安装、构建和运行游戏无需 Python 或 Pillow。要重生成时安装 Pillow，然后在项目根目录运行 `python scripts/generate-assets.py`。脚本使用固定随机种子。素材与项目以相同许可分发。

所有图采用透明 PNG，设计网格为 32×32 像素；使用整数倍缩放、最近邻纹理采样和像素对齐。纹理坐标从左上角开始、从零计数。家具与饰物是透明覆盖层，应叠在地表或地板上。屋顶、墙和地面是可重复的整格背景。

## 角色图集

`people.png` 为 384×448，即 12 列 × 14 行。每格 32×32。列 0–2 朝下、3–5 朝左、6–8 朝右、9–11 朝上；每个方向第一格为站立、其余两格是交替步态。行表示不同人物外观。各行依次使用以下设计参考名：店主、林恩、阿岚、米拉、布莱恩、薇拉、诺亚、伊莎、罗恩、塞拉、霍恩、艾达、梅芙、加尔。名字只是绘画参考，游戏可根据设定重新分配，但人物与头像应使用相同行号。

`portraits.png` 为 896×64，即 14 个 64×64 的头像，从 `people.png` 同行人物切取并最近邻放大。游戏世界中的人物建议锚点设在脚底，人物深度随脚部 y 坐标排序。

## 建筑图集

`buildings.png` 为 576×96，横向排列六个 96×96 透明建筑立面，依次为旅店、公会、市场、诊所、广场设施与镇门设施。屋顶与招牌配色不同，招牌图案依次是床、剑、天平、十字、喷泉与拱门。可作为街景图层选择性使用；建筑的可通行范围和交互点仍由地图规则决定。
