# 评议后的持续经营

在成功或失败评议后，可执行 `continue`。`chapter`、`endingReason`、`chapterDay` 保留首次结果；继续从当日日结后的下一日 00:00 开始并暂停。旧版 `continued` 缺省为 false，旧评议存档首次继续时记录原日数。`worldRunning` 是引擎与 Worker 的统一推进条件；已评议但尚未继续的世界不会前进。

首次继续和之后每五天，在未有同类别周期委托时产生一项采购与一项由已保存随机数决定区域的远征委托。采购要交付四份草药，奖励由发布时的库存决定；远征保留其地区、技能、补给和队伍规则。每项截止为开放日后第四日，已接任务到期失败，无人接取时采购可由具备条件的居民实际接取和结算。结算只对进行中的任务执行一次；已有同类任务进行时不可再接同类，避免一次远征的归属歧义。结束的周期委托在下一次刷新时归档，最多保留 40 条；原四项篇章委托始终保留。周期任务声望增加上限 50、单势力支持增加上限 20，不削减已有更高数值。

续营后可在公会使用 `guildWork`：每起始日一次，两小时按正常模拟推进，完成收入 12 金。如果开工时有待决远征选择则拒绝；工作中出现新的重要请求或远征选择则中断且不发报酬，次数仍消耗。`lastGuildWorkDay` 保存在存档中，跨午夜时按实际完成日记账。

`supply-cycles.ts` 为续营增加周期供需事件，细节见 DESIGN.md。高财力局的经营经济仍偏宽松；固定大小数值与存档字段受 JavaScript 安全整数范围限制，并非数学意义上的无限运行。
