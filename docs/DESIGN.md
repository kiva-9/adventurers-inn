# 设计记录

纯 TypeScript 世界是事实来源。Worker 每 100ms 按倍速推进 1/2/4 游戏分钟；所有随机由保存的 32 位 LCG 状态产生。界面提交命令并接收快照，不直接发放奖励。人物以需求、价格、预算、伤势、特质和信任选择工作、吃饭、治疗或休息，旅行中不能同时接待。当前实现仍需核查与任务书之间的差距。

起始 180 金币、24 食材、4 草药、3 张床、60 借款。热汤消耗 1 份食材，丰盛炖菜消耗 2 份；后者缓解疲劳。帮手工资 4/日，旅店租金 20/日；每五日借款产生 2 利息。采购食材每份 4 金币、草药每份 3 金币。镇公所和商队支付居民劳动所得，构成外部资金来源。远征消耗食材、耗时，目标技能与策略影响成功概率，路上可以决定继续或折返。

四项委托分为采购、调查、护送和救援；后三类需要不同远征成功。支持度、声望与现金共同决定许可。设施改造耗时两天。具体行为与平衡以测试记录为准，不将设计意图视为已验证效果。
